# Modelo Edge Impulse

Esta pasta receberá o pacote WebAssembly exportado pelo Edge Impulse.

O arquivo compactado deve ser colocado aqui sem renomear. Depois disso, a estrutura do pacote será inspecionada e o adaptador `../tinyml-adapter.js` será conectado à API gerada, preservando os arquivos originais do modelo.

Não inclua chaves de API, tokens ou credenciais nesta pasta.
